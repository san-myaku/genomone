# 🧬 ゲノモン (GENOMONE)

**ガチ育種選抜たまごっち** — 遺伝・育成・選抜の三位一体ミニ育種シミュレーター。

タマゴを孵し、世話して育て、♀♂を交配し、限られた飼育枠の中で「真に優れた血統」を
選抜して世代を重ねる。見かけの強さに釣られず、**遺伝的能力を見抜く選抜眼**が問われる。

依存ライブラリなし。`index.html` をブラウザで開くだけで遊べる。

```
genomone/
├── index.html    画面・UI
├── style.css     見た目
├── genetics.js   遺伝エンジン（減数分裂・受精・突然変異・表現型）
└── game.js       ゲーム本体（ライフサイクル・世話・交配・選抜・セーブ）
```

## 遊び方

### 1. 世話する（たまごっち要素）
タマゴは時間経過で孵化。**ごはん / あそぶ / そうじ / やすむ / くすり** で
`まんぷく・きげん・せいけつ・けんこう` を維持する。放置すると健康が落ち、**病気で死ぬ**。
幼少期の世話の質が、成体時の能力ボーナスと寿命を左右する。

### 2. 育種する（選抜交配）
成体（♀×♂）を交配するとタマゴが生まれる。
- **能力（ちから・すばやさ・たいりょく・こんじょう）** … 複数遺伝子座の相加効果（**ポリジーン／QTL**）
- **見た目（体色・模様・ツノ）** … **メンデル遺伝**（優性順位・不完全優性）
- 減数分裂時に低確率で**突然変異**が起き、世代を超えて能力が伸びる余地が生まれる。

### 3. 選抜する（ガチ要素）
飼育枠は **8体まで**。優秀な個体を残し、劣る個体は「にがす」。これが選抜圧。

## ★ 最重要コンセプト：見える強さ ≠ 遺伝能力

```
表現型 P = 遺伝的能力 G + 環境偏差 E + 育成補正 + トレーニング
```

画面に表示されるのは **P**。しかし子に伝わるのは **G（遺伝子）だけ**。
トレーニングや好環境で見かけ上強い個体を選んでも、その子は伸びない。
**🔬 DNA解析** で真の育種価(G)を確認し、Gの高い個体を選抜するのが攻略の核心。

近親交配は**近交係数**が上がるほど弱い子（近交弱勢）が生まれやすい。
血統管理と遺伝的多様性の維持もカギになる。

## 遺伝モデルの詳細
- 各個体は二倍体。量的形質は1形質あたり5遺伝子座 × アレル値0〜4の相加モデル。
- 体色は4アレルの優性順位制、模様は完全優性、ツノは不完全優性（ホモ/ヘテロで表現が変わる）。
- 表現型 = 育種価 + 個体固有の環境偏差 + 幼少期育成補正 + 後天トレーニング（上限あり・非遺伝）。
- 選抜を続ければ創始個体（能力G≈15〜30）から世代を重ね、能力G≈90超の血統を作り出せる。
