# 🧬 ゲノモン (GENOMONE)

**ガチ育種選抜たまごっち** — 遺伝・育成・選抜の三位一体ミニ育種シミュレーター。

かわいいゲノモンを世話して育て、♀×♂を交配し、限られた飼育枠の中で
「真に優れた血統」を選抜して世代を重ねる。見かけの強さに釣られず、
**遺伝的能力を見抜く選抜眼**が問われる。

依存ライブラリゼロ。`index.html` をブラウザで開くだけで遊べる（ビルド不要）。

```
genomone/
├── index.html    画面・レイアウト
├── style.css     あったかキャンディ・テーマ＋全アニメーション
├── genetics.js   遺伝エンジン（減数分裂・受精・突然変異・表現型）
├── creature.js   ゲノモンのお絵かき（SVG）＋表情・演出・パーティクル
├── audio.js      効果音シンセ（Web Audio・音声ファイル不要）
└── game.js       ゲーム本体（ライフサイクル・世話・交配・選抜・図鑑・殿堂・実績・セーブ）
```

## 遊び方

### ① そだてる（たまごっち）
タマゴは時間で孵化。**ごはん・あそぶ・そうじ・やすむ・くすり** で
`まんぷく・きげん・せいけつ・けんこう` を維持する。放置すると病気で星になる。
幼少期の世話の質が、成体時の能力ボーナスと寿命を左右する。
生息地のキャラを**タップでなでなで**♪ 状態に応じて表情がころころ変わる。

### ② かけあわせる（選抜交配）
成体（♀×♂）を交配するとタマゴが生まれる。
- **能力（ちから・すばやさ・たいりょく・こんじょう）** … 複数遺伝子座の相加効果（**ポリジーン／QTL**）
- **見た目** … **メンデル遺伝**：体色（優性順位）・模様（しま/みずたま/むじ）・目の形・体型・ツノ（不完全優性）
- 減数分裂時に低確率で**突然変異**。世代を超えて能力が伸び、まれに **✨シャイニー** が誕生！

### ③ えらびぬく（選抜）
飼育枠は **8体まで**。優秀な個体を残し、劣る個体は「にがす」。これが選抜圧。

## ★ 最重要：見える強さ ≠ 遺伝能力

```
表現型 P = 遺伝的能力 G + 環境偏差 E + 育成補正 + トレーニング
```

画面に表示されるのは **P**。しかし子に伝わるのは **G（遺伝子）だけ**。
トレーニングや好環境で見かけ上強い個体を選んでも、その子は伸びない。
**🔬 DNA解析** で真の育種価(G)を確認し、Gの高い個体を選抜するのが攻略の核心。
近親交配は**近交係数**が上がるほど弱い子（近交弱勢）が生まれやすい。

## やりこみ要素
- 📖 **図鑑** … 出会った見た目（体色×模様×目×体型×ツノ×✨）をコレクション
- 🏆 **殿堂** … 看取った／野に還した歴代最強トップ10を記録
- 🎖️ **実績** … 初孵化・第10世代・評価値360・シャイニー発見など12種

## 遺伝モデルの詳細
- 各個体は二倍体。量的形質は1形質あたり5遺伝子座 × アレル値0〜4の相加モデル（最大40＝能力100換算）。
- 体色6アレルの優性順位制、模様3アレルの優性順位制、目4種・体型3種、ツノは不完全優性（ホモ/ヘテロで表現が変わる）。
- 表現型 = 育種価 + 個体固有の環境偏差 + 幼少期育成補正 + 後天トレーニング（上限あり・非遺伝）。
- 選抜を続ければ創始個体（能力G≈15〜30）から、組換え＋突然変異＋選抜で能力G≈90超の血統を作れる。

## 技術メモ
- 純粋な HTML / CSS / JavaScript のみ。外部依存なし。GitHub Pages 等にそのまま公開可能。
- 1ゲーム日 = 実時間2分。`localStorage` に自動セーブ、閉じている間も育つ（放置上限あり）。
- 表情・まばたき・呼吸・しっぽ振りなどは CSS アニメーション、世話の反応はパーティクルで表現。
- `prefers-reduced-motion` 対応、スマホ縦画面までレスポンシブ。
